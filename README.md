# PC Info

Double-click `PCInfo.exe` to see this PC's brand, model number, serial number, Windows version,
processor, RAM, GPU and hard disk storage. Use **Copy All** or **Save to TXT** to share them.

## Run from source
    python pc_info.py

## Build the exe
Run `build.bat` (needs Python 3). The exe is created at `dist\PCInfo.exe` and can be
copied to any Windows 10/11 PC — no Python needed there.
